# Support

The Intent and Evidence Project Engine is maintained by one person. This page says what that means in practice.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/intent-evidence-project-engine/issues/new/choose).
  Use the bug report or feature request form so the maintainer has what is needed to act.
- **Response time:** best-effort, with no SLA. Nobody is on call, and a reply can take a while.
- **Security reports:** do not open a public issue. Follow [`SECURITY.md`](SECURITY.md), which uses
  GitHub private vulnerability reporting.
- **Versioning:** The package version (`iepe-core`, in `pyproject.toml`) and the protocol version (`IEPE-001`, in `VERSION`) are separate; the protocol is specified in [`docs/PROTOCOL.md`](docs/PROTOCOL.md).
